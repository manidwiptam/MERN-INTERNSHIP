Module :

> It's a file that contains reusable code.
    Code - can be Function or Variable or Objects.
> It can be used in another file.
> Uses of Module -
    1. Keep code in a organized manner.
    2. Reusable
    3. Easy to use.
    4. Help to remove redundancy.

> Common JS Module Default - use "require"
        syntax :
            module.exports = value; ----------- Export
            const variable = require("../filePath") ----------- Import
